# Famulus News

The Famulus News family at https://famulus.lettre.ai/news/: a landing page and one site per member (reference, science, university, visualization, 3d), in six languages
(DE, EN, FR, IT, ES, PL). Generated from the news workspace (`publication/rundbriefe/famulus-news`) by
`famulus-news export-pages`; do not edit by hand.
