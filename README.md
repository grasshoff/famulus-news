# Famulus

The public Famulus site, https://famulus.lettre.ai/news/

`/` holds Famulus News, the development news of the Famulus platform in six languages (DE, EN, FR, IT, ES, PL).
That folder is generated from the news workspace (`publication/rundbriefe/famulus-news`) by `famulus-news export-pages`;
do not edit it by hand. The root and any other folder belong to the site and are never touched by that export.
